# AI Media Factory

Cloud media production infrastructure, designed for operation through Claude Code.

## Project status

Repository initialization is complete. Production integrations and cloud execution are still pending implementation and validation.

## Operating principles

- Use official platform APIs and integrations.
- Keep credentials in the hosting provider's secret manager, never in source control.
- Require owner approval before public branding, initial content, publishing, or automated community replies are activated.
- Enforce configured spending limits before requesting billable generation.
- Keep an audit trail for asset rights, generation, editorial approval, publication, and cost.

This initial commit creates the default branch required by development tools. It does not activate publishing or incur paid service charges.
